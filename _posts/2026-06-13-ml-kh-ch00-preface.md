# AI, ML, និង DL — ខុសគ្នាយ៉ាងណា?

មួយរយៈនេះ **បញ្ញាសិប្បនិម្មិត** (artificial intelligence, AI) បានជ្រៀតចូលក្នុងស្ទើរគ្រប់វិស័យនៃជីវភាពរស់នៅរបស់យើង — Google Maps ដឹកនាំការធ្វើដំណើរ, Facebook tag មុខដោយស្វ័យប្រវត្តិ, Siri ស្តាប់សំឡេង, Netflix ណែនាំខ្សែភាពយន្ត។

ត្រូវយល់ឱ្យច្បាស់៖

- **AI (បញ្ញាសិប្បនិម្មិត)** — វាលធំជាងគេ។ គ្រប់បច្ចេកវិទ្យាដែលធ្វើឱ្យម៉ាស៊ីន "មានវិចារណញ្ញាណ" (សូម្បីច្បាប់សាមញ្ញ)។
- **ML (ការរៀនម៉ាស៊ីន, machine learning)** — សំណុំរងនៃ AI។ ម៉ាស៊ីនរៀន **ដោយខ្លួនឯងពីទិន្នន័យ** ដោយមិនចាំបាច់សរសេរច្បាប់ឱ្យវាដោយផ្ទាល់។
- **DL (ការរៀនជ្រៅ, deep learning)** — សំណុំរងនៃ ML។ ប្រើបណ្តាញសរសៃប្រសាទសិប្បនិម្មិត (neural networks) ដែលមានស្រទាប់ច្រើន។

![ទំនាក់ទំនងរវាង AI, ML, និង DL](/images/ml-series/dl_gray.png)

> **កំណត់សម្គាល់៖** DL ⊂ ML ⊂ AI (DL ស្ថិតក្នុង ML, ML ស្ថិតក្នុង AI)

# ហេតុអ្វី ML សំខាន់សម្រាប់កម្ពុជា?

ML មិនមែនជារឿងបរទេសទេ — វាកំពុងធ្វើការនៅកម្ពុជារួចហើយ៖

- **វិស័យហិរញ្ញវត្ថុ៖** ABA, ACLEDA, និង Wing ប្រើ ML ដើម្បីរកការក្លែងបន្លំ (fraud detection) ក្នុងប្រតិបត្តិការ Mobile Money។ ការវិភាគបែបបទប្រតិបត្តិការអាចទាញនិន្នាការគួរសង្ស័យក្នុងរយៈពេលប៉ុន្មានវិនាទី។
- **មីក្រូហិរញ្ញវត្ថុ៖** AMK, Prasac, LOLC ប្រើគំរូ ML ដើម្បីវាយតម្លៃហានិភ័យឥណទាន​ (credit scoring) សម្រាប់កសិករនិងម្ចាស់ SME ដែលគ្មានប្រវត្តិធនាគារ។
- **កសិកម្ម៖** គម្រោងព្យាករផលរ៉ូងស្រូវ (rice yield prediction) នៅខេត្តបាត់ដំបង, ព្រៃវែង, និងតាកែវ ដោយប្រើ ML លើទិន្នន័យអាកាសធាតុ, ដី, និងបទពិសោធន៍កសិករ។
- **ភាសាខ្មែរ (NLP)៖** Google Translate, Khmer OCR, ប្រព័ន្ធបំលែងសំឡេងជាអក្សរខ្មែរ — សុទ្ធតែប្រើ ML។
- **ទេសចរណ៍៖** ការព្យាករចំនួនភ្ញៀវនៅអង្គរវត្ត, ការកំណត់តម្លៃសណ្ឋាគារនៅព្រះសីហនុ។
- **ទូរគមនាគមន៍៖** Smart, Cellcard, Metfone ប្រើ ML ដើម្បីព្យាករកាត់ផ្ដាច់សេវា (churn prediction) និងណែនាំកញ្ចប់សេវាដែលសមស្រប។

នៅពេលរៀន ML, អ្នកមិនត្រឹមតែរៀនបច្ចេកវិទ្យាបរទេសទេ — អ្នករៀនឧបករណ៍ដែលអាចដោះស្រាយបញ្ហាជាក់ស្ដែងនៅផ្ទះរបស់អ្នក។

# តម្រូវការចំណេះដឹង

មុនពេលចាប់ផ្តើម, អ្នកគួរស្គាល់៖

- **គណិតវិទ្យាកម្រិតមហាវិទ្យាល័យ៖**
  - **ពិជគណិតលីនេអ៊ែរ** (linear algebra) — វ៉ិចទ័រ, ម៉ាទ្រីស
  - **កាល់គុលម៉ាទ្រីស** (matrix calculus) — និស្សន្ទ, ក្រាដ្យង់
  - **ប្រូបាប៊ីលីតេនិងស្ថិតិ** (probability and statistics)
- **ភាសាសរសេរកម្មវិធី៖** Python ជាមួយបណ្ណាល័យ **NumPy** និង **scikit-learn**

ប្រសិនបើខ្វះចំណេះដឹងគណិតវិទ្យាខ្លះ, កុំបារម្ភ — **ផ្នែកទី ១ (មេរៀន ៩ មេរៀន)** នឹងរំឭកគ្រប់អ្វីដែលចាំបាច់សម្រាប់ ML។

# វិធីសាស្ត្ររបស់ស៊េរី

រាល់មេរៀននីមួយៗនឹងបង្ហាញតាមរចនាសម្ព័ន្ធ ១០ ផ្នែក៖

1. **សង្ខេប** (Summary/TL;DR) — អ្វីដែលត្រូវចងចាំក្នុង 30 វិនាទី
2. **ហេតុអ្វីសំខាន់?** — ហេតុអ្វីប្រធានបទនេះមានសារៈប្រយោជន៍
3. **ពាក្យបច្ចេកទេសថ្មី** — តារាងពាក្យ ខ្មែរ ↔ English
4. **គំនិតវិចារណញ្ញាណ** (intuition) — តើមនុស្សគិតយ៉ាងណា?
5. **និយមន័យ និងគណិតវិទ្យា** — រូបមន្តច្បាស់លាស់
6. **ឧទាហរណ៍** — ប្រើទិន្នន័យពិត (កម្ពុជា ឬ​ឧទាហរណ៍សាមញ្ញ)
7. **កូដ Python** — NumPy / scikit-learn
8. **ការអនុវត្តន៍ជាក់ស្ដែង** — ការប្រើពិតប្រាកដក្នុងឧស្សាហកម្ម
9. **លំហាត់** — ៣ លំហាត់ជាមួយចម្លើយ
10. **មេរៀនបន្ទាប់** — អ្វីដែលនឹងបន្តបន្ទាប់

> **គោលការណ៍មួយ៖** *តែងតែចាប់ផ្តើមពីរបស់សាមញ្ញ*។ ក្បួនដោះស្រាយសាមញ្ញឱ្យយើងយល់បញ្ហាបានលឿន មុននឹងផ្លាស់ទៅរកគំរូស្មុគស្មាញ។

# អំពីការដាក់សញ្ញា

- **ពាក្យបច្ចេកទេសខ្មែរ** នឹងភ្ជាប់ជាមួយពាក្យអង់គ្លេសដើមនៅពេលលើកឡើងលើកដំបូង — ឧ. *ការរៀនម៉ាស៊ីន (machine learning, ML)*។
- **ឈ្មោះបណ្ណាល័យ Python** (numpy, scikit-learn, pytorch) — រក្សាជាភាសាអង់គ្លេស។
- **រូបមន្តគណិតវិទ្យា** — រក្សាជានិមិត្តសញ្ញាស្តង់ដារ (មិនបកប្រែជាខ្មែរ)។
- **កូដប្រភព** — Jupyter notebook នៅចុងជំពូកនីមួយៗ។
- **ឧទាហរណ៍** — ប្រើទិន្នន័យកម្ពុជានៅពេលអាច (ស្រូវ, លំនៅឋាន, មីក្រូហិរញ្ញវត្ថុ, ល។)។
